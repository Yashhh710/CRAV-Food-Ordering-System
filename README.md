## About CRAV

**CRAV – From Craving to Doorstep** is a food ordering and restaurant management web application designed to provide customers with a convenient food ordering experience and administrators with tools to manage restaurant operations.

The project combines a customer-facing food ordering website with an administrative control center, bringing essential restaurant operations into one platform.

## Key Features

</div>

### Customer Features

- Browse food categories and menu items.
- Explore burger and pizza menus.
- Add products to the shopping cart.
- Manage wishlist items.
- Complete the checkout process.
- Demo QR payment experience.
- Track order status.
- User registration and login.
- Table reservation functionality.

### Admin Features

- Admin authentication.
- Centralized dashboard.
- Order management.
- Product and category management.
- Delivery partner management.
- Reports and analytics.

### Additional Features

- Responsive web interface.
- REST API integration.
- JWT-based authentication.
- Demo payment workflow.
- Customer and admin interfaces.

## Installation & Setup

### 1. Clone the Repository

</div>

```bash
git clone https://github.com/Yashhh710/CRAV-Food-Ordering-System.git
```

### 2. Navigate to the Project

```bash
cd CRAV-Food-Ordering-System
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root:

```env
PORT=5001
NODE_ENV=development
```

Add any other environment variables required by your server configuration.

### 5. Start the Application

**Development mode:**

```bash
npm run dev
```

**Production mode:**

```bash
npm start
```
